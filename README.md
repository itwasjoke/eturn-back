# Eturn Application

## Eturn - сервис электронных очередей 

Это модуль в приложении Smart University, а также сайт по адресу digital.etu.ru/eturn/

Он позволяет создавать автоматизированные очереди, которые упростят учебный процесс для студентов и сотрудников. Студенты могут самостоятельно создавать очереди и администрировать их

Основное приемущество - контроль над временем. Можно дистанционно понять, когда нужно  подойти к преподавателю

## Setup

```shell
docker compose build
docker compose up
```

App will start at port 37111
